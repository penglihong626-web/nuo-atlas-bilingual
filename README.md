## 英文版与手机排版（2026-10-15）

当前版本默认显示英文，导航栏左侧的 `中文 / EN` 按钮可随时切换，并记住本机的语言选择。网址参数 `?lang=en`、`?lang=zh` 可直接指定语言；切换保留已有草稿和游戏进度。英文覆盖文化图谱、483 条档案、创作工坊及地图小游戏。

中英文共用道具与操作图标，箭头和加减号使用同一套单色字形。手机英文版已调整筛选框、比较按钮、绘画色板、图鉴、分析表头和地图提示位置；在 320、360、390、430 像素宽度下检查无页面横向溢出，地图小游戏保留一屏布局。

发布前通过 12 组交互与数据回归测试及页面结构检查。本地 QA 截图和缓存不纳入发布。

静态网站。改版以“基础认识 → 文化图谱（按需探索） → 留下参考 → 表达心意 → 绘画 → 留存或赠予”为主线，沿用原有黑金视觉、483条国内档案与研究图谱。当前包含第一轮基础流程、第二轮体验完善，以及第三轮的区域填色与局部编辑。

## 第一轮内容

- 六件萍乡湘东彭国龙作品的图像、线稿、角色关键词、传统用途与场景、当代心意启发和资料链接。先理解角色与生活的关系，再留下创作参考。
- 重点样本与完整星图共享创作参考收藏。
- 自用、赠予共用创作工具，赠予可填写称呼和署名。
- 固定900×1000画布、参考线稿、项目配色、笔刷、对称、撤销/重做和作品卡预览。
- 图像、文字、参考和步骤一起自动保存为本机草稿；最多保存10件本机作品，支持重新打开。
- 下载包含图像、心意、个人解释和文化出处的PNG作品卡。
- 文化图谱位于基础认识之后、选择参考与创作之前，按需展开与加载。章节顺序为历史长河、地域分布、傩面具星图、语义与情绪、色彩图谱、世界面具、中外对比、趣味小游戏。
- 图谱入口保留“直接进入创作”，可先选底稿绘画，完成作品卡前再补齐心意与文化参考。手机顶部目录与桌面导航均按页面顺序排列；跳去创作不会自动收起图谱。

草稿使用 `nuo_drawing_draft_v1`，其 `journey` 字段与PNG一起写入；已保存作品使用 `nuo_journey_works_v1`。读取旧版独立文字草稿时兼容 `nuo_journey_draft_v1`。数据仅存在当前浏览器与网址下，清除站点数据会丢失；导出图片可作留存。保存失败会显示提示，不会自动删除旧作品。

## 第二轮内容

- 入门介绍按“是什么、当地怎样使用、从哪些作品开始”组织；六张样本支持作品图与线稿并排观察。

- 纸面、单张参考线稿与笔触分开处理。线稿可独立改色、缩放、平移、锁定或替换，橡皮只擦笔触；调整支持撤销与重做。
- 草稿与新保存作品包含可编辑图层，重新打开后可继续调整。旧版压平图像完整保留，无法逆向拆分；切换参考会替换当前线稿并保留笔触。
- 赠予作品先呈现称呼、心意和署名，再呈现图像、创作解释与文化出处；自用作品保留相应的留存引导。
- 窄屏工具与表单布局、画布附近的保存提示、输入时的悬浮栏遮挡、草稿加载期间的继续入口已完善。绘画和游戏快捷键仅在各自有效操作区域生效。

第二轮可编辑信息存于统一草稿及作品记录的 `drawing` 字段（内部版本2）；第三轮升级为版本3，并兼容读取版本2，现有存储键和外层版本保持兼容。作品图片可下载留存；当前没有可导入的图层文件或云端备份。

## 第三轮：让新手从一处改变开始（2026-10-04）

- **区域填色**：选择颜色后轻点闭合区域，参考线条和笔触继续保留在上方。拖动、取消或多指操作不会触发填色；连到画布边缘的区域拒绝填入，避免误涂整张纸。填错可以撤销，或在“纸面与线稿”中清除填色。
- **参考局部编辑**：在参考线稿上拖出矩形，或输入位置和大小，将该处线条拆成独立局部，调整颜色、大小、位置和旋转。每件作品最多8处局部；取出的原位置保留剪口，撤销拆分可以还原。现有SVG没有五官分组，这项操作是手动框选，不是自动识别眼睛或冠饰。
- **操作顺序**：工坊引导用户先调整构图，再填色和添画，最后说明文化参考与个人选择。主要工具与色板保持可见，笔刷细项折叠；局部控制位于画布下方。手机端延续原地反馈，不自动跳转。
- **作品完整性**：填色、局部、纸面、线稿、笔触一同进入撤销、草稿、保存作品、重新编辑及PNG输出。作品卡会补回画布实际使用的线稿与局部来源，即使用户已移除该收藏；仍保留对应的选择理由。

已通过绘画、填色算法、来源追溯、星图手势及页面结构检查。在独立测试地址的375像素视区，实际完成判官区域填色、撤销重做、数字框选、局部改色/大小/位置/旋转、保存作品、刷新重开和PNG下载；下载图已打开核对图像、文字与来源。375和1280像素视区没有横向溢出。真实iPhone Safari的拖拽手感与多指操作仍需实机测试。

第三轮 `drawing.version = 3` 增加 `fills` PNG、参考线稿的 `cuts` 与 `parts`（来源、裁切范围及变换）。版本2分层作品与更早的压平图像仍可打开；不能从压平图像中恢复原始图层。

填色不会自动修补线条缺口，低对比或很细的线可能无法分隔区域；可撤销、补线后再试。填色固定在纸面位置，不随线稿或局部移动，因此先调构图再上色。矩形截取只提取当前参考线稿，不能提取已画笔触；与已有剪口重叠的范围会拒绝再次截取。更换或移除主线稿保留已拆出的局部、填色和笔触。

## 第三轮补充：分区填色与自由绘画（初版，底稿已由下节替换）

- 工坊提供两种创作方式。新草稿默认进入分区填色选择，旧草稿保持自由绘画；切换方式不会清空画面。
- 预制判官、文财神、龙王三张底稿，各16个大块面，分别参考档案0317、0319、0325。数据与预览位于 `coloring-templates.js` 和 `assets/coloring/`。它们是当代手绘简化练习稿，不是原作复原或传统配色指南。
- 分区填色通过预定义闭合路径命中，支持点画布或按块面名称点色，不依赖细碎原线稿的像素闭合。可以重新换色、撤销、重做，也可以留白。
- 可先分区填色，再切到自由绘画添笔触，之后继续分区改色；现有勾线笔、软笔、柔喷笔、橡皮、对称及原线稿局部编辑保留。自由模式在分区底稿上使用油漆桶时仍操作预定义块面。
- 重复选择当前底稿保留颜色；换另一张底稿或原线稿会替换底稿，并可撤销，已有笔画、局部与纸面填色数据保留。分区底稿绘于纸面填色之上，旧填色被底稿覆盖的部分可在返回原线稿后看见。分区底稿本身是固定构图，局部截取仍适用于原参考线稿。
- 保持 `drawing.version = 3`，追加可选的 `template: {id, colors}` 与 `creationMethod`。缺失字段的旧记录按无模板的自由绘画恢复。可信模板目录提供文化来源，作品卡和PNG明确标注当代简化底稿。

已实际验证手机375像素视区：画布点色、区域名称填色、切自由绘画添笔再切回、换模板后撤销恢复、保存及刷新重开，并下载查看包含模板说明和文化来源的PNG。自动检查覆盖上层区域命中、两种方式切换、填色与笔触隔离、旧版兼容、来源及多指/滑动取消。真实iPhone Safari触控手感仍需实机复测。

## 创作台与色环（2026-10-05）

画笔、粗细、撤销与完成位于画布上方，颜色位于下方；“到画布”滚动到整个创作台。桌面及手机竖屏按可用高度显示画布，绘图仍保持900×1000像素。画笔与填色可在上方就近切换；设置、24色色板和色环在台内展开，不推开画布，关闭面板的点击不会透到画布。

画布下方常驻8个常用色；更多颜色提供24色，色环可调色相、浓淡、明暗，也支持3/6位十六进制色号。两种创作方式共用当前色，自选色随草稿恢复。连续拖动只更新选色，停止后合并保存，关闭或离页时保存最终颜色；选色本身不产生绘画撤销步骤。

已在375×667手机宽度下验证上下工具栏同屏、近处切笔/填色、拖动色环不移位、任意色号、油漆桶填色、软笔添画与撤销，以及刷新后的颜色恢复。真实iPhone Safari手势仍需实机确认。新增 `color-picker.js` / `color-picker.css`，无额外依赖；检查包括 `node tests/color-picker.test.cjs` 及现有绘画、流程和页面结构验证。
