## 本地 STL 是什么

文件位于用户资料的 `00_傩面具项目总整理_2026-05-03/06_3D模型与打印文件/0001_printable.stl`。同目录元数据记录输入为 `assets/masks/0001.svg`；二进制 STL 文件头写明它来自该 SVG。实查网格为 688,916 个三角面，34,445,884 字节，与元数据一致。

`12_脚本与生成工具/svg_mask_to_printable_3d.cjs` 展示了完整生成方式：

- 把 SVG 栅格化，再闭合线稿间隙并保留主要轮廓。
- 给轮廓构造前后表面和侧壁，添加固定厚度与线条浮雕。
- 用通用拱面及几个固定位置的高斯凸起模拟鼻、眼、口附近起伏。
- 输出 STL 与按高度着色的预览图，没有读入实物点云、深度照片或多角度测量。

元数据给出的打印尺寸为宽 106.48 mm、高 160 mm、最小厚度 3.2 mm、最大深度 26.1 mm。这里的尺寸和深度是生成参数，不是实物测量值。

网站 0001 号条目为安徽池州“招魂使者”。当前网站的 0001.svg 与原资料最新版网页内的同号 SVG，其画布尺寸和路径数据相同，但文件整体哈希不同。因此可以记录它的二维来源对应关系；不能把推导出来的深度称为这件面具的真实几何。33 MB、近 69 万面的文件也不宜原样作为手机端默认加载资源。

## 如何实际补齐

1. **先明确三种资产身份。** 实物扫描、依据多角度资料人工建模、当代创作模型分别标记；二维线稿浮雕和 AI 推导另列，不计入实物扫描覆盖率。
2. **先完成正在使用的三件样本。** 判官 0317、文财神 0319、龙王 0325 应各自采集或制作独立几何，核对冠饰、眉眼、鼻口、边缘及背面厚度。没有侧面与背面依据的部分应标记为设计推断。
3. **取得对应原作及模型使用依据。** 记录模型作者或扫描单位、对应实物、资料来源、是否允许网页展示、修改、下载和商业使用。仅取得图片不能自动证明可以发布其三维衍生模型。
4. **让绘画与几何对应。** 为每个模型整理可用于创作的 UV 或命名区域，并验证眉眼、冠饰等颜色落在正确部位；不能把整张矩形画布继续直接包到任意面具上。
5. **分批扩展 483 条档案。** 每一件先建立身份与授权记录，再验收前、侧、后视图及几何，制作手机端轻量版本，最后更新清单中的对应状态。没有模型的条目继续显示二维资料。

最终可交付的“全部模型”应以逐件验收的覆盖表为准，不能靠复制同一个面具壳体、批量挤出线稿或收集不相关面具来填满数量。
