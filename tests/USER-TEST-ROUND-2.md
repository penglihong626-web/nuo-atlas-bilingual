# 第二轮真实用户测试

**状态：待招募、待执行。本文是测试方案和空白记录模板，不是测试结果。** 自动检查和浏览器模拟操作不能代替这里的真实参与者测试。

## 要验证的问题

用户能否先认识傩面及其地方背景，再从文化参考作出自己的创作选择？完成后的作品，能否帮助自用者留下期待、帮助真实接收者理解心意？

重点检验“看过什么 → 怎样理解 → 因此改变了什么”。不以绘画水平、阅读页数或满意度分数代替证据，也不要求用户采用页面提供的心意关键词。

## 参与者与准备

- 自用组：3—4名创作者，为自己制作作品。
- 赠予组：2—4名创作者，每人选择一位真实接收者；接收者愿意参加，并单独反馈。
- 创作者每场15—20分钟。接收者另安排5—8分钟，首次阅读时不让创作者在旁解释。
- 记录参与者此前对傩文化的了解程度、使用设备和浏览器。优先邀请首次接触网站的人；至少让自用、赠予各一人使用真实手机触控。
- 记录被测版本、网址和设备。先确认基本流程可用；每场使用独立测试环境，避免混入上位参与者的草稿。
- 告知参与者：测试的是网站，可以使用愿意分享的内容，不必披露私人经历；可以拒绝录音、停止或不送出作品。以编号记录，姓名和具体关系不必进入报告。
- 主持人不先讲角色含义、不展示“标准答案”，也不代操作。先让参与者尝试；需要提示时，逐字记录提示和发生位置。

## 创作者任务：15—20分钟

| 时间 | 给参与者的任务 | 主持人观察与记录 |
| --- | --- | --- |
| 0—2分钟 | “请把它当成你第一次打开的网站，看看你觉得这里可以做什么。” | 首先注意什么；能否理解从认识文化到创作的方向；是否寻找返回或继续入口。记录原话。 |
| 2—5分钟 | “请找一个你愿意继续了解的面具，按自己的兴趣浏览。找到后，说说你现在知道了什么。” | 自发阅读了哪些角色/场景/来源，是否只看外形；能否说出一个有资料支持的角色或地方事实。若只能复述情绪词，再问一次“你是从哪里看到的？”并标为追问后回答。 |
| 5—12分钟 | 自用：“请用这里的参考，为接下来的自己留下一份期待，做成一件作品。”赠予：“请为那位真实接收者制作一件作品，表达一句你愿意告诉对方的话。” | 如何比较、选择或更换参考；是否能从文化内容形成自己的解释；画布操作是否顺畅。不要指定必须选什么角色、颜色或心意。 |
| 12—15分钟 | 在已有文字和绘画后：“请先离开这页，再回来继续刚才的作品。” | 先记录当前文字、参考和画面，再按参与者习惯返回或刷新。核对内容是否恢复；是否找得到继续创作；是否发生覆盖或丢失。 |
| 15—18分钟 | “请完成这件作品，并把它保存到你之后找得到的地方。”赠予者再检查收件称呼、署名和留言，决定是否自行发送作品卡。 | 保存、导出与重新找到作品是否可独立完成；图像、心意、个人解释和来源能否读到。记录用户对‘保存在本机’的理解，不把保存误当公开或云端备份。 |
| 18—20分钟 | “请指出作品中的一个选择，说说为什么这样做。资料里怎样解释它？你自己的意思是什么？” | 分别记录文化依据与个人解释；追问“哪一处内容让你改变或确认了选择？”如果没有文化影响，如实记“未观察到”，不引导补理由。 |

时间紧时保留创作、恢复、交付和解释任务，结束讨论可以缩短。没有完成的步骤标为“未测试”，不让主持人接管来制造完成率。

## 接收者任务：另行5—8分钟

只发送创作者确认愿意分享的最终作品卡。由创作者自行发送；测试者不代替创作者向他人发消息。先记录创作者希望传达的一句话，再收集接收者的独立解释。

1. 请接收者像平常收到作品一样查看，先不介绍创作流程：“你读到了什么？你觉得对方想对你表达什么？”
2. “你能找到这张面具参考了什么，以及创作者自己的解释吗？”记录其实际寻找路径和表述。
3. “如果你想留着它，你会怎么做？”观察是否能按自己的习惯保存；接收者也可以选择不保存。
4. 最后才让接收者提出想问创作者的问题；不要求回复、点赞或回赠。记录是否因为文字难读、信息缺失或表达歧义而无法理解。

接收者理解了心意但不保存、不回复，不自动算失败。若参与者只是觉得对方“应该会喜欢”，没有实际接收者反馈，则赠予接收环节仍为“未测试”。

## 成功、受阻与失败的依据

每项标记“独立完成 / 提示后完成 / 未完成 / 未测试”，并附动作或原话证据。

| 检验点 | 成功证据 | 受阻或失败证据 |
| --- | --- | --- |
| 基础认识 | 能用自己的话说出所选样本的地方来源或角色背景，并指出阅读位置。 | 只把样本当情绪标签；将个人联想当作确定的传统寓意；经追问仍找不到依据。 |
| 文化参与选择 | 能指出一条实际看过的文化内容，以及它怎样影响了参考、线条、文字或整体表达。 | 没有可观察的联系，只复述界面例句；需要主持人替其建立联系。此项未成立时不能仅凭作品完成就宣称文化转译有效。 |
| 自主表达 | 心意与选择可由用户解释；能够区分资料介绍和自己的当代意义。 | 以为系统已替自己决定角色含义；无法修改为自己想表达的内容；把示例当唯一允许答案。 |
| 中断恢复 | 回来后画面、文字、参考及步骤与中断前相符，能够继续。 | 丢失、错配、覆盖，或无法发现继续入口。任何确认的数据丢失都优先修复。 |
| 留存与查找 | 能导出可读作品卡，之后找回；清楚本机保存的范围。 | 下载失败、图片截断、字太小、来源缺失；误以为已上传云端或公开。 |
| 自用结果 | 创作者认为作品表述准确，并能说明愿意如何留存或回看；如需改动，能指明具体位置。 | 只能辨认是装饰图，无法从作品读回最初期待；保存后找不到或需要主持人解释。 |
| 赠予接收 | 接收者独立读出的核心心意与创作者记录相符，能分清留言和文化参考。 | 误读对象、署名或用意；图像遮挡文字；必须由创作者当场补充解释才能理解。 |

这是一轮小样本形成性测试，只报告人数和具体证据，不推算普遍比例。某一任务两人出现同一阻碍，即列为下一轮优先修正点；文化误解或数据丢失即使只出现一次，也要核对原因。
